📄 PDF Tools

All files are processed on your device. Nothing is uploaded to any server.

PDF to JPG / PNG

Choose a PDF. Every page is converted to an image. Convert first, then download the images.

Merge PDF

Add 2 or more PDFs, drag them into the order you want, then merge.

    Split PDF

    Creates one separate PDF for every page. Convert first, then download them one by one.

    Delete Pages

    Type the pages to remove, like 2 or 1,3-5. The rest is saved as a new PDF.

    Extract Pages

    Type the pages to keep, like 1 or 2-4,7. Only those pages go into the new PDF.

    Rotate Pages

    Turn pages by 90°, 180° or 270°. Leave pages empty to rotate all pages.

    Add Watermark

    Your text is stamped diagonally across every page.

    Compress PDF

    Rebuilds the PDF smaller. Works best on scanned / photo PDFs.

    Note: pages are rebuilt as images, so text inside will no longer be selectable.

    PDF Size — Target KB

    Shrinks the PDF to fit under your target size — handy for online forms.

    Note: pages are rebuilt as images, so text inside will no longer be selectable. If the target is too small to reach, you get the smallest possible file and a message saying so.

    Lock PDF

    Adds a real password lock (AES-256). The file will ask for this password to open.

    Unlock PDF

    Removes the password from a locked PDF. You must know the current password.

    🔒 This PDF is locked

    That password was wrong — please try again.

    The password is used only to open the file. It is never saved anywhere.
