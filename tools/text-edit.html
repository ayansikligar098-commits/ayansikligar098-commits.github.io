✏️ Text Edit

All files are processed on your device. Nothing is uploaded to any server.

PDF Text Editor

Pick a PDF, tap a line of text on the page (or in the list below it), type the replacement, and download the edited PDF. The old line is cleaned off the page first, then your text is written in the same place, at the same size and colour.

The password is used only to open the file. It is never saved anywhere.

Text colour Background

    The replacement is written in a standard font matched as closely as possible to the original line's size and colour. It may not be the exact same font as the document's own font. Works on PDFs that contain real text (most PDFs made by a computer). If a page is a scanned photo with no real text, the app reads it with the on-device word finder (OCR) and you can edit the lines it finds — OCR can misread letters, so check each line before applying. If a PDF is locked, you will be asked for its password — the password is never saved.

    Photo Text Editor — Beta, experimental

    Pick a photo, let the app find the words in it, tap a word, type the replacement and download the edited photo. The old word is cleaned off and the new word is written in its place.

    Honest warning: this is beta quality. It works best on clear photos of printed text on a plain background. On busy or photo backgrounds the cleaned patch can stay visible, and the new word is written in a standard font, so it will not look exactly like the original writing.
    Word colour Background

    Reading the text happens fully on this device (offline word finder). The first run can take a little while. After a word is replaced, tap "Find text in this photo" again if you want to change another word.
